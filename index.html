Optimizador de TXD

Para skins de GTA San Andreas (SA-MP y open.mp). Elegí el .DFF y el .TXD de la misma skin: el modelo queda igual y el TXD se guarda con las texturas más livianas.

Todo se procesa en el navegador. Los archivos no se suben a ningún servidor.

1. Elegí los archivos

2. Ajustes

75%
Si no sabés qué poner, dejalo como está.
El DFF no se modifica.

3. Listo

Se descarga un .zip con el DFF original y el TXD optimizado. Guardá los originales hasta probar la skin en el juego.

Si abriste el archivo con doble clic, vas a poder elegir los archivos pero el optimizador no va a cargar. Usá la página publicada o serví la carpeta con python -m http.server.
